# وتيرة — متتبع تمارين عربي للـ iPhone

تطبيق SwiftUI أصلي لتخطيط التمارين وتسجيل التقدّم، باسم **Coach : 3BIID - AB**. يعمل محليًا مع SwiftData ومزامنة CloudKit الخاصة بالمستخدم عند توافر صلاحيات التوقيع. تسجيل الدخول والحسابات عبر الأجهزة مؤجّلان بطلب المالك؛ لا توجد خدمة خلفية في هذه النسخة.

**حالة المصدر:** الإصدار الحالي ١٫٢٫١، البناء ٤، في [المستودع](https://github.com/ghghgh5052-beep/-). يضيف حذف الجلسات وإلغاء التمرين دون حفظ، مع تحديث الأرقام الشخصية والاقتراحات من السجل المتبقي. يحتفظ بالتدريب المقترح وخريطة العضلات والرسوم التشريحية الستة والستين والملكية. أكّد المالك تشغيل إصدار سابق على iPhone؛ هذه الملاحظة لا تثبت اختبار الإصدار الجديد. راجع [حالة التحقق](docs/VALIDATION.md) وartifact المطابق لمعرّف commit لنتائج البناء والاختبارات؛ التكاملات التي تحتاج صلاحيات خاصة تعتمد على التوقيع وتجربة الجهاز.

## حذف جلسة أو إلغاء تمرين

من **التمرين ← جلساتك السابقة** افتح الجلسة، ثم اختر **حذف الجلسة** أسفل ملخصها وأكّد الحذف. يمكنك أيضًا سحب صف الجلسة إلى اليمين لإظهار الحذف في الواجهة العربية. أثناء جلسة نشطة أو متوقفة، اختر **إلغاء التمرين دون حفظ** أسفل الجولات. الإلغاء يحذف المسودة وكل جولاتها، ولا ينشئ جلسة مكتملة، ويوقف مؤقت الراحة والتنبيه والنشاط الحي.

الحذف نهائي داخل التطبيق: يزيل الجولات، ويعيد حساب الأرقام الشخصية والتقدم والاقتراحات والتعافي التقديري من الجلسات المتبقية. تبقى الخطط والتمارين والقياسات والصور محفوظة. إن سبق تصدير الجلسة إلى تطبيق الصحة، احذف نسختها من هناك أيضًا؛ يظهر ذلك في تأكيد الحذف. النسخ الاحتياطية التي صدّرتها سابقًا لا تتغير، وقد يعيد استيرادها الجلسة المحذوفة. لا يتطلب التحديث ترحيلًا جديدًا أو تغيير المعرّفات والصلاحيات.

## التدريب المقترح وخريطة العضلات

من **التمرين ← اقترح لي تمرينًا** حدّد الهدف والمستوى والوقت والأدوات وخطوة زيادة الوزن، ثم راجع الاقتراح وعدّل أرقامه قبل البدء. توليد المعاينة يحفظ التفضيلات، ولا ينشئ جلسة. من **تقدّمي ← خريطة العضلات والتعافي التقديري** يمكنك مشاهدة اثنتي عشرة منطقة وقراءة حملها وآخر تدريب والجولات. أثناء جلسة نشطة، قائمة خيارات التمرين تتضمن **اقتراح الأوزان والتكرارات** لتطبيق اقتراح مراجع على جولات العمل غير المكتملة فقط.

الحساب محلي بقواعد موثقة، دون خدمة ذكاء اصطناعي أو نموذج تعلم آلي. لا يقيس الاستشفاء الفعلي، ولا يفترض أن غياب السجل يعني جاهزية كاملة. بيانات العضلات والأدوات مرتبطة بمعرّفات تمارين المكتبة الأساسية الستة والستين؛ التمارين الخاصة لا تدخل في الحساب، وتمارين الثبات والكارديو لا تدخل في توليد الجلسة. التفاصيل وقواعد زيادة الوزن وحدود التقدير والترحيل في [SMART_TRAINING.md](docs/SMART_TRAINING.md).

## البناء على Mac

المتطلبات: Xcode **16.4** وPython 3 وiOS Simulator. الحد الأدنى للتطبيق iOS **17.0**. يُستخدم مترجم Swift 6 الموجود في Xcode 16.4 مع وضع اللغة Swift 5 لتوافق Swift 5.9+. لا توجد حزم Swift خارجية أو CocoaPods أو أدوات توليد مطلوبة للبناء؛ مشروع Xcode مُدرج بالفعل.

1. افتح `Wateera.xcodeproj` واختر مخطط `Wateera`.
2. عدّل `Config/Identifiers.xcconfig` بالمعرّفات التي تملكها قبل إعداد الحاويات والتوقيع.
3. شغّل الاختبارات، ثم أنشئ الحزمة دون توقيع:

```bash
sudo xcode-select -s /Applications/Xcode_16.4.app/Contents/Developer
python3 scripts/validate_project.py
bash scripts/test_ios.sh
bash scripts/build_unsigned_ipa.sh
```

الناتج: `build/Wateera-unsigned.ipa` ومعه SHA-256، معرّف commit، إصدار Xcode، وسجل البناء وملفات entitlements بعد توسيع المتغيرات داخل `build/signing/`. يستخدم [السكريبت الفعلي](scripts/build_unsigned_ipa.sh) `xcodebuild archive CODE_SIGNING_ALLOWED=NO`، ثم ينسخ التطبيق مع امتداده إلى `Payload/` ويضغطه. يُفشل البناء عند تحذيرات Swift/Clang.

لا يكتب السكريبت فوق أرشيف سابق. للبناء التالي:

```bash
OUTPUT_DIR="$PWD/build/m2" bash scripts/build_unsigned_ipa.sh
TEST_OUTPUT_DIR="$PWD/build/tests-m2" bash scripts/test_ios.sh
```

يمكن تحديد المحاكي باستخدام `IOS_SIMULATOR_DESTINATION='platform=iOS Simulator,id=UUID'`. للتشغيل المباشر على iPhone من Xcode، يلزم توفير فريق وملفات provisioning وتفعيل `CODE_SIGNING_ALLOWED=YES` في إعدادات البناء؛ القيمة الافتراضية `NO` مقصودة.

## GitHub Actions

المستودع الحالي متصل بالفعل. يحتوي المشروع على [workflow](.github/workflows/ios.yml) يعمل عند push وبالتشغيل اليدوي من Actions → iOS tests and unsigned IPA → Run workflow. يستخدم `macos-15` وXcode 16.4، ويجري الاختبارات قبل الأرشفة: المجموعة كاملة على شاشة صغيرة، ثم مسار الواجهة على شاشة كبيرة بالوضع الداكن والأرقام الغربية. لا يحتاج شهادة أو ملف provisioning أو أسرار توقيع. استخدام runners في المستودعات الخاصة يخضع لحصة حساب GitHub.

```bash
git clone https://github.com/ghghgh5052-beep/-.git wateera-ios
cd wateera-ios
```

بعد نجاح العمل، نزّل artifact باسم `Wateera-unsigned-<commit>`؛ يحتوي على IPA وملفات التوقيع المذكورة. نتائج XCTest ولقطة اختبار الواجهة وسجلات الأخطاء في artifact منفصل. لا توجد خطوات TestFlight أو App Store Connect.

## التوقيع اليدوي

إذا أعادت خدمة التوقيع إصدار الحزمة دون صلاحيات iCloud أو الصحة أو مجموعة التطبيقات، تعمل النسخة الحالية محليًا وتعرض حالة الحفظ في الإعدادات. لا تحاول تهيئة CloudKit قبل فحص صلاحيات التوقيع الحالي. راجع [إصلاح الإغلاق بعد التوقيع](docs/STARTUP_FIX.md) وحدود هذا الفحص. الاشتراك في خدمة توقيع لا يثبت امتلاك صلاحيات الحاويات المسجلة لهذا التطبيق.

الحزمة غير الموقعة لا تُثبت مباشرة. يجب توقيع **امتداد FitnessWidgets.appex أولًا ثم Fitness.app** باستخدام الملفات المناسبة لكل App ID. لا توجد شهادات أو ملفات provisioning ضمن المستودع. التفاصيل والمعرّفات والصلاحيات في [CAPABILITIES.md](docs/CAPABILITIES.md). اختيار بيئة CloudKit وAPS في ملف الإعدادات يجب أن يطابق ملف provisioning الذي ستستخدمه.

## تنظيم المصدر

| المجلد | المسؤولية |
| --- | --- |
| `Fitness/App` | بدء التطبيق، القفل، التوجيه وApp Intents |
| `Fitness/Core` | نماذج SwiftData وإصداراتها، الحسابات، بيانات المكتبة، محرك التدريب المقترح، الاستيراد والتفضيلات |
| `Fitness/Features` | الخطط والتقويم والمكتبة وتسجيل المجموعات والتقدم والإعدادات؛ المعاينة وخريطة العضلات في `Features/Smart` |
| `Fitness/Services` | منطق الجلسة القابل للملاحظة، تفضيلات التدريب ولقطات السجل، الإشعارات، HealthKit، حالة المزامنة والقفل |
| `Fitness/Shared` | مكونات الواجهة وعقود Live Activity والويدجت |
| `FitnessWidgets` | امتداد WidgetKit وDynamic Island |
| `FitnessTests` / `FitnessUITests` | حسابات وترحيل وتعارضات ونسخ احتياطي ومسار الواجهة |

تستخدم الواجهة Observation و`@Query` و`@Bindable`؛ يملك `WorkoutCoordinator` حالة الجلسة والمؤقت والحفظ والتكاملات. الحسابات منفصلة وقابلة للاختبار. تعرض الواجهة العربية فقط، وتفرض RTL وتقويمًا ميلاديًا مع بداية أسبوع قابلة للتعديل. تستخدم الرسوم انعكاس Swift Charts الأصلي مع RTL دون عكس إضافي يلغي الاتجاه. النصوص تستخدم خط النظام العربي وDynamic Type، وتتكيف شاشة تسجيل المجموعات مع أحجام الإتاحة. تُحدد القيمة الحالية عند التركيز على حقول التسجيل والحاسبات، فتستبدلها الكتابة مباشرة بدل إلحاق الأرقام بها.

## سلوك البيانات والخصوصية

- جميع الأوزان محفوظة بالكجم والأطوال بالسم؛ إعداد الوحدات يغيّر العرض والإدخال فقط.
- الحفظ مستمر بعد التعديلات الصالحة، ويحفظ التوقف والاستئناف وموعد انتهاء الراحة. يستعيد التطبيق الجلسة بعد إعادة فتحه. تُطلب الإشعارات عند الاستخدام فقط.
- يدعم CloudKit الخصوصي كل النماذج بما فيها الصور والتفضيلات. الأقفال وصلاحيات الصحة جهازية ولا تُنسخ إلى جهاز آخر. بيانات الويدجت ملخص صغير داخل App Group، دون الصور أو HealthKit.
- يتعامل SwiftData مع سجلات CloudKit الأصلية. يحل التطبيق نسخ UUID المكررة باختيار أحدث سجل كامل، مع حسم ثابت عند تساوي التاريخ. للتفضيلات سجل واحد وللجدول خطة نشطة واحدة. تبقى الجلسات المستقلة المتزامنة محفوظة، وتُستعاد الأحدث.
- يتطلب تغيير حساب iCloud قرارًا واعيًا: بيانات الجهاز المحلية باقية، وقد تُرفع إلى الحساب الجديد. هذا تطبيق شخصي يفترض استخدام حساب iCloud الخاص بك؛ احتفظ بنسخة قبل تبديله.
- الصور المستوردة تُصغّر إلى حد أقصى ٢٠٠٠ بكسل وتُعاد كتابتها دون metadata الأصلية. قفل الصور حاجز واجهة ببصمة/رمز الجهاز؛ لا يدعي التطبيق إنشاء خزنة تشفير مستقلة. التخزين داخل sandbox يعتمد على حماية iOS للجهاز.
- تقديرات 1RM تدعم إيبلي وبرزيكي. تاريخ PR يستخدم إيبلي افتراضيًا، ويقارن تكرارات الأرقام الشخصية عند الوزن نفسه، ويستبعد الإحماء والجلسات غير المكتملة.
- التخفيف يظهر كأسبوع مخطط بحسب تاريخ البرنامج. لا يغيّر الأوزان قسرًا؛ عدّل مجموعات الأسبوع أو الأوزان وفق خطتك.
- التدريب المقترح يعمل دون اتصال: يستعمل الجلسات المكتملة الصالحة، ويستبعد الإحماء والتمارين الخاصة. بيانات التمرين الأساسي المخفي تبقى مؤثرة في تقدير الحمل دون إدراجه في جلسة مقترحة جديدة. الاقتراح لا يغيّر سجلًا مكتملًا، ولا يُطبّق على جولات العمل الحالية إلا بطلبك.
- مخطط SwiftData الحالي V3 يضيف تفضيلات التدريب فقط، ويحافظ على نماذج V1/V2 ومسار التخزين والمراجع. يبدأ التطبيق بالتفضيلات الافتراضية عند عدم وجود سجل، ويحفظها عند توليد الاقتراح.
- الإشعارات المحلية تُسجّل لدى النظام، لكن الصوت ووقت العرض يعتمدان على إذن المستخدم وFocus وسياسات iOS. Live Activity يتوقف عند حدود النظام الزمنية ويحتاج دعمه على الجهاز؛ Dynamic Island يظهر على الأجهزة التي تدعمه.

## التصدير والاستيراد

JSON نسخة كاملة بصيغة `formatVersion: 2` مع المعرّفات والمراجع والصور بترميز Base64 وتفضيلات التدريب في `trainingProfiles`. يقبل الاستيراد النسخ القديمة بصيغة ١ والجديدة بصيغة ٢؛ غياب تفضيلات التدريب في النسخة القديمة لا يحذف التفضيلات المحلية. التواريخ ISO-8601 UTC بدقة المللي ثانية؛ تُقبل نسخ التواريخ دون الكسور أيضًا. CSV جدول UTF-8 برؤوس عربية يحفظ المكتبة اللازمة والجلسات والحركات والمجموعات وقياسات الجسم، ويتعامل مع الفواصل والاقتباسات والأسطر الجديدة. لا يحتوي CSV على الصور أو الخطط أو الأهداف أو التفضيلات بما فيها ملف التدريب؛ استخدم JSON للنسخة الكاملة.

الاستيراد **دمج**: السجل الأحدث يحل محل الأقدم؛ عند تاريخ متساوٍ يبقى السجل المحلي. يُرفض الملف غير الصالح أو المكرر المعرّفات قبل الكتابة. تُحفظ التعديلات السابقة أولًا، ثم تُحفظ تغييرات الاستيراد مرة واحدة مع التراجع عنها عند الفشل. حد الاستيراد ٥١٢ ميجابايت. لا يحذف الاستيراد بيانات غير موجودة في الملف، وتُبنى الأرقام الشخصية مجددًا بعده. لا تُستورد نسخة أثناء جلسة نشطة.

## تعديل المصدر

بعد إضافة ملف Swift أو تعديل حقول نموذج النسخ الاحتياطي، حدّث الملفات المولّدة والتزم بها:

```bash
python3 scripts/generate_backup_records.py
python3 scripts/generate_project.py
python3 scripts/validate_project.py
```

مولّد المشروع والنسخ يستخدمان مكتبة Python القياسية فقط. الأيقونة والألوان وصورة الإطلاق مُدرجة. لإعادة توليد الرسوم الهندسية فقط، يحتاج `scripts/generate_assets.py` إلى Pillow؛ هذه أداة تطوير اختيارية لا تُضمّن في التطبيق ولا تُستخدم في CI.

Apple Watch مرحلة ثانية غير منفذة، وفق نطاق الطلب. مراحل التسليم وبيانات التحقق المطلوبة موثقة في [MILESTONES.md](docs/MILESTONES.md).

رسوم التمارين الأصلية محفوظة في `Fitness/Resources/Assets.xcassets/exercise_*.imageset`، وتُعرض كاملة دون قص من المكتبة ومن الجلسة النشطة. البداية على اليمين والنهاية على اليسار؛ تمارين الثبات تعرض التجهيز ثم وضع الثبات. رُبطت الصور بمعرّفات التمارين الثابتة، فلا تتغيّر الصورة عند إعادة التسمية ولا يُنسب رسم لتمرين مخصّص بمجرد تشابه الاسم. [توثيق الرسوم](docs/EXERCISE_ART.md) يوضح المنشأ و[مجموعة تعليمات التوليد](scripts/exercise_art_prompts.json)، ويحتفظ `Fitness/Resources/ExerciseArtManifest.json` ببصمات الملفات. التوليد استخدم أداة image_gen المدمجة؛ لا تعتمد عملية بناء التطبيق على الأداة أو مفتاح API.
